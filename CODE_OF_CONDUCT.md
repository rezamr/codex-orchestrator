# Code of Conduct

We want this project to be useful, technical, and welcoming.

Contributors are expected to:

- discuss ideas and code rather than attacking people,
- give specific, actionable review feedback,
- respect differing levels of experience,
- avoid harassment, discrimination, threats, and deliberate disruption,
- protect private information and security reports,
- assume good faith while still being precise about technical risks.

Maintainers may edit, hide, or remove contributions that materially violate these expectations and may restrict participation when necessary to protect the community.

If a conduct issue cannot be handled safely in public, contact a maintainer through an available private GitHub channel.
