# Support

Codex Orchestrator is a community open-source project.

## Use GitHub issues for

- reproducible bugs,
- feature proposals,
- platform compatibility reports,
- documentation problems,
- integration regressions.

Before filing a bug, include:
- application version/commit,
- operating system,
- Codex version,
- whether the problem reproduces after restart,
- relevant redacted logs,
- exact state shown by the job/session timeline.

Never include access tokens, credentials, private source code, or sensitive project paths unless you intentionally choose to disclose them.

## Not official OpenAI support

This repository is independent from OpenAI. Problems with an OpenAI account, billing, plan limits, or the Codex service itself should be handled through the appropriate official OpenAI support channel.
